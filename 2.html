Regra CSS

A regra CSS define o estilo visual utilizado em uma página web, com personalização das cores, imagens, tamanhos, posições, espaçacamento e fontes. Para tornar isso possível, o CSS possui seletores, propriedades e valores. Por exemplo: 

        <style>

        h1, h2{
            text-align: center;
        }
        p{
            font-family: Verdana, Geneva, Tahoma, sans-serif;
        }

        img{
            height: 40px;
            width:40px;
        }
        </style>

No exemplo acima, é utilizado a tag <style> para colocar a regra CSS e estilizar a página. E onde se encaixa os seletores, propriedades e valores no exemplo?

Seletores - Define qual parte da regra você quer estilizar
h1, h2{}
p{}
img{}

Propriedades - O que você deseja alterar no seletor
text-align:
font-family:
height:
width:

Valores - Como o elemento vai ser alterado
center:
Verdana, Geneva, Tahoma, sans-serif;
40px;
10px;

Além disso, a regra CSS possui pseudo classe (palavra chave adicionada a um seletor que define seu estado), pseudo elemento (Palavra chave adicionada a um seletor que permiti estilizá-lo em partes específicas), e animação simples (palavra chave que adiciona animação a um seletor)
