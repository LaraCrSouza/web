O que é JavaScript?

Motivação para a criação do JavaScript

Antigamente a web era centrada em texto plano através da linguagem de marcação HTML, que representava a estrutura e conteudo de uma pagina Web. Porém, um dos problemas dessa linguagem é que essas páginas web eram estáticas. Então para dar mais vida ao HTML e permitir que essas páginas fossem mais dinâmicas, o Brendan Eich foi recrutado em 1995, para ser um dos programadores da NCC. Ele foi o criador do javaScript que seria “cola” entre o HTML e o resto dos sistemas.

Diferença entre execução no navegador e no servidor

A diferença entre eles está onde o código é processado, ou seja, quando é trabalhado no "lado navegador" o código é executado no navegador. Quando é trabalhado "no lado do servidor", o código é executado no servidor.

Conceito de sandbox no navegador.

Sandbox é um mecanismo de segurança usado para executar um aplicativo em um ambiente restrito. Ele impede que ameaças acessem os computadores, os arquivos ou o resto do sistema operacional.

document, console e alert

Document: O objeto global document permite acessar, modificar, criar ou deletar elementos HTML através de JavaScript;
console: O objeto global console fornece acesso ao console de ferramentas de desenvolvedor do navegador. Pode ser usado para inspecionar variáveis, objetos e rastrear possíveis erros;
alert: o objeto global alert exibe um popup modal na tela com uma mensagem e um botão de "OK". Até que o usuário feche essa caixa de mensagem, ele bloqueia a interação com o resto da página.
