Como declarar variáveis

Usamos let ou var para declarar váriaveis

var nome; //cria uma variável global com identificador nome
let idade; //cria uma variável local com identificador idade

Tratamento de eventos em JavaScript

Tratamos evento em js usando addEventListener que vincula uma função a um eveneto específico do DOM.

Exemplo

document.addEventListener('click', function(){ console.log('Clique detectado!'); });

Eventos Comuns disponiveis nos Navegadores

  • Click - evento de clique
  • mouseOver - eveneto de mouse sobre o elemento
  • mouseOut - eveneto de mouse fora do elemento
  • mouseenter - evento de mouse entrando no elemento
  • keypress - evento de tecla pressionada
  • keydown - evento de tecla pressionada
  • keyup - evento de tecla solta
  • submit - evento de envio de formulário da tag form
  • DOMContentLoaded - evento disparado quando o documento HTML é completamente carregado e parseado
  • change - eveneto disparado quando o valor de um elemento de formulário
