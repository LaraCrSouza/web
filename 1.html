LINGUAGEM DE MARCAÇÃO - HTML

HTML

   HTML (HyperText Markup Language) é uma linguagem de marcação que é utilizada para organizar elementos em uma tela que posteriormente serão visualizadas pelos usuários, ou seja, é a linguagem que organiza a página da web. Em sua estrutura, são usados tags para definir os elementos dispostos na tela, como parágrafos, títulos, links, listas, tabela, entre outros.

PAPEL DO HTML NA WEB

   O HTML é responsável por organizar onde um elemento aparece e como serão apresentados em uma página WEB. Sem HTML, a web não teria funcionalidades como tem hoje.

Exemplos de tags utilizadas no HTML:

  • <p> - Isto é um parágrafo
  • <br> - Serve para quebrar uma linha
  • <hr> - Serve para criar uma linha de separação horizontal
  • <b> - Texto em negrito
